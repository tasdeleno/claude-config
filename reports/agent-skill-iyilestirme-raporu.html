Filo geneli bulgular

  1. Zincir yalnız prose ile işliyor. Aynı oturumdaki reviewer çiftlerinin %39'u aynı dosya:satırı raporluyor (php↔security 17, php↔ts 15). Önemsiz olmayan commit'lerin ~%26'sı reviewer'sız gitmiş (kaba ölçüm).
  2. Bulgular doğrulanmadan uygulanıyor. CLAUDE.md:25 "ciddi bulguları uygula" diyor; Anthropic'in code-review'u bulgu başına doğrulayıcı koşturuyor. Bir öneri daha önce düzeltilmiş bir hatayı geri getirecekti.
  3. ponytail personası her subagent'a giriyor (329/329). Plugin'in kendi seçeneği var: ponytail-subagent.js:8-11.
  4. Windows kabuk hataları tekrarlıyor: python3 yok, bash'te %TEMP%, bash'te PowerShell cmdlet'i, Masaüstü yolunda mojibake. 19 dosya yerine tek bir SubagentStart hook'u yeter.
  5. Frontmatter'da effort, maxTurns, color hiç yok. settings.json'daki claude-sonnet-5: xhigh kaydı yüzünden effort'u açıkça sabitlemek gerekebilir (miras davranışı doğrulanmadı).
  6. Model seçimi doğru. Haiku'ya geçmek önerilmiyor: superpowers ölçümünde haiku 2-3× tur harcadı.
  7. Doc Stop hook çoğunlukla gürültü: doc-update-reminder.js:35 quotePath yüzünden Türkçe adlı .md'yi kaynak sayıyor; :49 imzası her edit'te değişip tekrar blokluyor.
  8. autoresearch scout-block hook'u reviewer'ların node_modules/.bin, *.log ve Expo .d.ts erişimini engelliyor.
  9. Sorun olmayanlar: CRLF (LF doğrulandı), agent description bütçesi (4.4k karakter), VoltAgent/wshobson reviewer'ları bizimkilerden zayıf.
  10. Memory tutarsızlığı: ecc-kurulumu.md "geniş fan-out → Explore" diyor, CLAUDE.md:59 Explore'u yasaklıyor.

A · ECC kökenli agent ve skill'ler

En güçlü itiraz: "upstream dokunmadı" ölçümü yalnız aynı yoldaki değişikliği görür; dosyalar taşınırsa ya da toplu format değişirse sessizce sıfır görünür. Geçmiş, geleceği garanti etmez.

Öneri: Klonda local branch tut, git merge origin/main ile 3-yollu birleştir. Script yazma; git diff --stat ve git log --diff-filter=R yeter. Upstream değişti + yerel 0 → kopyala; ikisi de değişti → git merge-file; upstream değişmedi → dokunma.

Neden iyi: Bugünkü veride çakışma yok, güncelleme başına birkaç dakika. Yerel agent'lar aynı isimli plugin agent'larını zaten bastırıyor (resmi doküman). Risk: elle kopyalama adımı unutulabilir. Alternatif: ECC'yi tam plugin olarak kurmak; bilinçli kurulmayan hook ve skill'leri geri getirir.

Ne zaman yanlış olur: Upstream agent dosyalarını aktif değiştirmeye başlarsa; o zaman ECC'yi fork'la ve local branch'i fork'ta tut.

B · Plugin skill'leri (impeccable, ui-ux-pro-max, autoresearch)

En güçlü itiraz: CLAUDE.md kuralı deterministik değil. Aynı isimli yerel skill plugin skill'ini gölgelemez, ikisi de yüklenir; model çelişen iki talimatı birden görür.

Öneri: Cache'te asla düzenleme yapma. Tercihleri CLAUDE.md'ye yaz, genel düzeltmeleri upstream'e PR olarak gönder, düzenli güncelle.

Alternatif (ağır özelleştirme gerekirse): Plugin'i /plugin ile kapatıp skill'i ~/.claude/skills/'e vendor et (graphify-windows deseni) ya da kendi fork'unu ref+sha pinli girişle ekle; version alanını sil.

Ne zaman yanlış olur: Plugin metnindeki bir hata iş akışını bozuyorsa ve upstream PR'ı kabul etmiyorsa.

C · Tamamen yerel varlıklar

Buna karşı güçlü bir argüman yok, çünkü upstream yok. Doğrudan düzenle, dotfiles reposunda versiyonla. İstisnalar: claude.ai'deki eski synced proje-checklist'i kapat; orchestration gibi junction skill'leri setup.ps1'e ekle.
